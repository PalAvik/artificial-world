The goal: a model where a span of a sequence can be expressed as text tokens or as image tokens and the model behaves the same either way — same next-token distribution, same downstream answer, enough information retained to regenerate the span in either direction.

This plan does three things to that idea. It replaces "equivalence" with a quantity you can actually measure. It solves the abstract-word problem constructively — you don't need a picture of "the", you need a picture of the word "the". And it puts measurement before training, so that a cheap three-week study can kill the project before it eats ten weeks.

The figure the whole project is aiming at is the invariance–informativeness frontier. Cross-modal invariance is trivially achievable by throwing information away. The contribution is showing where current VLMs sit on that trade-off, and moving it.

01

What "equivalence" can and cannot mean

The original framing — replace a text token with the corresponding image tokens and the model understands it the same — has three problems. Each has to be designed around rather than ignored.

There is no bijection

One word maps to N image patches, with N varying by resolution and content. There is no token-for-token swap.

ConsequenceSubstitution operates on spans, and equivalence is asserted at the merge position — the first position after the span, where the model has had to integrate it. The span positions themselves should differ; forcing them to match is a modeling error, and one we ablate explicitly.

There is no canonical rendering

"Dog" has many images. "From" has none in the referential sense.

ConsequenceThree substitution tiers with different relations and different success criteria, rather than one relation pretending to cover the whole vocabulary.

Reconstruction is asymmetric

text → image → text can be near-lossless: render glyphs, read them back. image → text → image cannot be. A 448×448 image carries far more bits than any caption of it — demanding accurate reconstruction there is asking for a violation of the source coding theorem.

ConsequenceReconstruction is never a single number. It is a rate–distortion curve, and distortion is measured task-conditionally — does the reconstruction answer the same questions? — not pixel-wise. A semantically identical but pixel-different dog has succeeded at the thing we care about.

The reframed goal

For a task distribution T and a substitution operator σ that re-expresses a span in another modality, the model's behaviour on σ(x) should differ from its behaviour on x by no more than the model's own variation across two same-modality paraphrases of that span.

That last clause is the load-bearing one. It converts an unbounded "how close is close enough" into a ratio with a natural target of 1.0.

02

Three tiers of substitution

Three different relations, three different success criteria. Conflating them is the main way this project produces uninterpretable numbers.

Tier A · referential

Concrete

"a dog" ⇄ ▨ region crop

Bridged by grounding. Natively annotated in Flickr30k Entities and Visual Genome region descriptions — phrase↔box pairs, no synthesis needed.

Invariance should be achievable but lossy: the image specifies a particular dog, the phrase specifies a class. Condition on questions answerable from the phrase alone.

Existing VLMs are already partly aligned here. This is the control, not the contribution.

Tier B · orthographic

Renderable

"the" ⇄ ▨ glyphs of "the"

Bridged by typography. Works for every token in the vocabulary — function words, punctuation, subword fragments. Synthesized on demand, unlimited, with font, size, background and noise as ablation axes.

Information-preserving in principle: the pixels contain the string exactly. Any behavioural gap is attributable purely to internal routing — the OCR pathway landing somewhere the embedding table doesn't.

The centre of the project. No semantic ambiguity, no annotation noise, no grounding error. Strong prior that current VLMs fail here badly — a result worth reporting on its own.

Tier C · relational

Structural

"on top of" ⇄ ▨ spatial arrangement

Bridged by synthetic scenes with programmatic ground truth (CLEVR-style), plus GQA's relation annotations.

Hardest tier, likely the largest gaps.

If entities transfer across modalities but relations don't, that asymmetry is the strongest world-model claim in the paper — it says multimodal pretraining fuses nouns and not structure.

Tier B is where the abstract-word problem dissolves. The question stops being "what does from look like" — unanswerable — and becomes "does the model treat rendered-the the way it treats token-the", which is a clean, controlled, unlimited-data experiment. A sub-study falls straight out of it: does the gap scale with word frequency, concreteness, or length? A gap that vanishes for concrete nouns but persists for function words would say something genuinely new about what multimodal pretraining does and does not fuse.

03

The metric suite, built first

Nothing else gets written until these exist. Notation: context C containing span s; V_T is C with s as text tokens, V_I is C with s as image tokens.

Distributional

Symmetric Jensen–Shannon divergence between the two views' next-token distributions, teacher-forced over a shared continuation. JSD rather than KL: symmetric, so neither view is privileged, and bounded, so items are comparable. Report the full distribution — the tail matters more than the mean.

Geometric, with the offset factored out

At the merge position, per layer, compare h_T and h_I by raw cosine distance and by offset-free distance — the same, after subtracting the per-modality batch mean. A constant per-modality translation is harmless if the downstream readout is affine. Reporting only the raw distance conflates a benign offset with genuine representational divergence, which is a recurring flaw in how the modality gap gets reported.

Normalized MSG — the headline number

A raw distance is uninterpretable. Is 0.3 large? Normalize by the model's own within-modality variation:

normalized MSG = d( h(V_T) , h(V_I) ) ½ [ d(h(V_T), h(V_T′)) + d(h(V_I), h(V_I′)) ]

V_T′ is a text paraphrase of the span; V_I′ is a different image of the same content — a different photo for Tier A, a different font or background for Tier B.

MSG ≈ 1 Crossing modalities costs no more than rephrasing. This is the target, and it is the operational definition of "free-flowing".
MSG ≫ 1 Modality dominates content.

The denominator is what makes the suite credible — which makes the paraphrase and re-render machinery a Phase 0 dependency, not an afterthought.

The informativeness probe

Invariance is trivially maximized by mapping everything to a constant. Guard against it: train a linear probe on h at the merge position to recover the identity of the substituted span, and track probe accuracy alongside MSG at every checkpoint.

Cycle consistency

T → I → T: render the span, feed it, ask the model to recover the string. Exact match and character error rate. Near-lossless is the expectation; failure here is a pure routing failure.

I → T → I: encode the span to text, regenerate an image from it, compare. Not with pixel metrics — with (a) embedding similarity in a third-party encoder held out from training, and (b) a VQA agreement score: pose a fixed question set to the original and the reconstruction, measure answer agreement. Both directions reported as rate–distortion curves by sweeping the intermediate budget.

04

Hypotheses, and what would kill them

H1 The gap exists. In an off-the-shelf 2B VLM, normalized MSG ≫ 1 across all three tiers — a cross-modal restatement costs far more than a within-modality paraphrase.
H2 The gap is structured, not uniform. Ordered Tier A < Tier B < Tier C, and within Tier B correlated with abstractness and function-word status rather than string length.
H3 Much of it is a removable offset. A substantial fraction of the geometric gap is a constant per-modality mean offset the readout could ignore; the residual is far smaller. If this holds, the problem is much more tractable than the modality-gap literature suggests.
H4 It is trainable. The ISO objective drives normalized MSG toward 1.0 without degrading standard VLM benchmarks beyond a small, stated margin.
H5 The real claim. Training for substitution invariance improves compositional and relational generalization — it buys world-model quality, not just a tidier representation. Tested on held-out relational composition, never on the training tasks.
Kill criteria — written before any results exist
  • H1 fails (gap already ≈ 1 everywhere): the phenomenon doesn't exist at this scale. The training program has no target to aim at — drop, don't proceed.
  • H3 fails badly and H4 shows invariance rising only as probe decodability falls: the objective is buying invariance by destroying information. One redesign, then stop.
  • H4 succeeds but H5 fails: a negative result, still publishable as a measurement paper. Write it as the measurement paper it is — don't oversell it as world-model progress.

Made operational: four dated gates

Each gate has a date, a number, and a decision. The decision is made on the date with the numbers that exist on that date — not a week later, and not after "one more run".

Any two gate failures ends the project. A phase overrunning its wall clock by more than 50% is cut, not extended. Every gate decision gets written down on its date — a gate silently rolled forward has failed at its only job. And no new run starts until the previous run's row is filled in the run log.

05

The ISO objective

Invariant Substitution Objective — five terms, each of which has to justify its presence.

L = L_LM Standard next-token loss on modality-mixed sequences.
+ λ_d L_dist Symmetric JSD between the two views' next-token distributions, with alternating stop-gradient — each view teaches the other. A fixed text-teacher would bake in exactly the text-centrism we're trying to remove.
+ λ_r L_repr Offset-free distance between merge-position hidden states. Applied only at merge positions and after — never on the span tokens themselves, which have different cardinality and should differ.
+ λ_c L_cycle Regenerate the swapped span in the opposite modality.
+ λ_g L_gen The anti-collapse anchor, and not optional. It is the structural reason the model cannot satisfy the invariance terms by discarding content. If Phase 3 slips, substitute a reconstruction proxy so the anchor exists from Phase 2 onward.

Curriculum: Tier B first — clean, unlimited, information-preserving — then A, then C. LoRA before full fine-tuning, to establish cheaply that the objective does anything at all.

Ablations that must run

AblationQuestion it answers
L_repr on span positions tooIs forcing span-level matching harmful, as the cardinality argument predicts?
drop L_genDoes invariance collapse the representation without the anchor?
fixed teacher vs alternatingDoes a privileged modality bake in text-centrism?
Tier B only vs all tiersDoes orthographic invariance transfer to referential?
render-augmentation onlyIs plain data augmentation the whole effect?

That last row is the reviewer's first question and the most likely way this result gets deflated. Run it early, not at the end.

06

Phases

One scope decision forced by the hardware: pixel-level image generation is out of scope for v1. On a single A100 in ten weeks, a generative decoder trained to publication quality is not achievable, and chasing it is the most likely way to finish with nothing. The anti-collapse anchor becomes feature-space reconstruction — predicting the frozen vision encoder's features for the swapped span — which gives the same structural guarantee at a fraction of the cost. The T→I→T cycle still runs in full, since read-back needs no generation. Pixel reconstruction is future work, where the hardware says it belongs.

07

Base model, compute, risks

Qwen/Qwen3.5-2B — released March 2026 — is a text-only LLM. It has no vision encoder, so it cannot host this experiment as written. The Qwen3.5 small line is 0.8B / 2B / 4B / 9B, all text.

  • Workhorse: Qwen3-VL-2B. Confirmed to exist, right size, native interleaved text/image context, and strong OCR — which matters a great deal for Tier B. Understanding-only, which is fine through Phase 2.
  • Check first: whether the Qwen3.5-VL line ships a ≤4B variant. Sources conflict on whether Qwen3.5's vision capability is a separate VL series or folded into the main line, and this could not be resolved from the authoring container. If a small Qwen3.5-VL exists, prefer it and keep Qwen3-VL-2B as the generational control.
  • Keep Qwen3.5-2B as the text-only ablation. Genuinely useful for isolating what the vision tower contributes versus what the LM already does with rendered text descriptions.
  • Phase 3 needs either a discrete visual tokenizer and decoder bolted onto the VLM, or a unified any-to-any base. Decide at the Phase 2/3 boundary with Phase 1 data in hand — don't pre-commit.

Compute

Ten weeks on one A100 is roughly 1,680 GPU-hours. The plan spends about 190. At 2B parameters with a frozen vision tower, the GPU sits idle most of the time — compute is not the binding constraint here, engineering time is, and so is the number of distinct ideas testable before the clock runs out. That is why the gates are strict about decisions rather than about compute.

Four choices make it fit comfortably: freeze the vision tower and cache image features once, so the encoder leaves the training loop entirely; render spans as narrow strips rather than square canvases, costing ~25 visual tokens instead of several hundred; LoRA for every ablation with a single full fine-tune to confirm; and a hard 50M-token cap per run, on the principle that a run needing more than six hours to show signal has the wrong config.

Risks

  • Collapse. The dominant failure mode. Watched every checkpoint, not at the end.
  • The augmentation deflation. "You just trained on rendered text." Pre-empted by the ablation table and by H5's held-out compositional test.
  • Tier A annotation noise swamping the signal — grounding boxes are imprecise. Mitigated by leading with Tier B, where ground truth is exact by construction.
  • OCR ceiling. If the base model can't reliably read rendered spans, Tier B measures OCR failure rather than representational geometry. Check this in week 1 with a read-back accuracy test — it gates the entire Tier B design and costs almost nothing.
08

Open questions

Would you ship Phase 1 alone if Gate 2 fails?

Deciding yes now is what makes the kill criteria real rather than decorative.

Do you accept the pixel-generation descope?

It's the right call for one A100 in ten weeks, but it means v1 has no image-generation result. If that's unacceptable for the venue you're targeting, the honest alternative is a longer timeline, not a compressed one.

Which deadline?

It determines whether the Gate 1 measurement study ships as its own workshop paper or folds into the main submission — and the ten-week clock above assumes it starts now.
